# The Metabolic Child

An interactive learning module on approaching a child with an inborn error of metabolism, designed for MBBS undergraduates, paediatric postgraduates and faculty, with Indian clinical context.

## Start learning

[Open the public learner module](https://vikramsakaleshpurkumar-byte.github.io/Vikkypaedia-Metabolic-Child-MOOC/)

Download this repository with **Code → Download ZIP**, extract it, and open **offline.html** in a modern browser. The complete course runs offline; reference links need internet access.

The modular version starts at `index.html`. It uses `style.css`, `data.js` and `course.js` from the same directory. No installation, build step, API key or account is needed. Any static web server can serve these files.

## What is included

- Three learner roles and selectable Must Know, Nice to Know and Good to Know depth.
- Twenty-one lessons with 105 teaching sections: ten core clinical rooms and an eleven-chapter PCNA masterclass.
- Four fictional patient journeys with 12 clinical decisions.
- 138 authored questions overall, including five evaluated questions in every room, baseline, cases and role-specific final practice.
- Answer explanations, confidence ratings, retries and a personal learning record.
- A faculty pathway-writing workshop and downloadable study guides.
- 56 annotated source records within the course, including all eleven articles in the supplied 2018 *Pediatric Clinics of North America* IEM review issue.

First-attempt performance is retained separately from corrected practice. Progress and reflections stay in the current browser; download personal records before changing devices or clearing browser data. Do not enter patient-identifying information.

## Editing

Edit teaching content in `data.js`, interactions in `course.js` and presentation in `style.css`. `offline.html` is a self-contained snapshot; changes to the modular files must also be incorporated into that snapshot before distributing an updated offline edition.
